04 // OPEN API

{{$.T "签名规则一眼看完"}}

{{$.T "与控制台同一套权限模型：密钥属于谁，就以谁的身份读写。"}}

{{$.T "# 待签串以 LF 连接，body 为空时对空串取摘要"}}
base = AppKey + LF + METHOD + LF + path + LF
     + timestamp + LF + nonce + LF + sha256hex(body)

{{$.T "# 签名即 HMAC-SHA256 的十六进制小写"}}
sign = HMAC-SHA256(Secret, base)

{{$.T "# 校验顺序：时间戳窗口 → nonce 去重 → 签名比对"}}
--endpoints
